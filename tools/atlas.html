PARAMYTH ATLAS — floor topology by site and depth

It draws the void rather than the rock. Each tile is one floor's room graph: occupied cells, the links between them, and the stairs. Read it down a column to see depth vary within one site; read it across a row to see sites differ from each other. A generator blind to an axis prints identical tiles along that axis, which is invisible from inside a room and obvious here.
